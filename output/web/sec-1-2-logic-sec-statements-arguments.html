    Section 0.1 Statements, Arguments, and Truth Tables

    Subsection Overview

    Logic is not the study of the content of an argument. Logic is the study of the structure of an argument. A logical analysis will never be able to tell you whether or not a particular claim has merit; it will only tell you if the truth of the conclusion follows necessarily from the truth of the premises.
    🔗
    What do I mean by the “structure” of an argument?
    🔗
    Consider the following arguments.
    🔗
    Argument 1:
    🔗
    If \(x > 0\) and \(x^2 = 4\text{,}\) then \(x = 2\text{.}\)
    🔗
    Therefore, if \(x \neq 2\text{,}\) then \(x^2 \neq 4\) or \(x \leq 0\text{.}\)
    🔗
    🔗
    Argument 2:
    🔗
    If I like Math and I like Data Science, I will like Discrete Mathematics.
    🔗
    Therefore, if I do not like Discrete Mathematics, then I do not like Math or I do not like Data Science.
    🔗
    🔗
    The content of these arguments is very different, but the structure is the same. They are both of the form:
    🔗
    If \(p\) and \(q\text{,}\) then \(r\text{.}\)
    🔗
    Therefore, if not \(r\text{,}\) then not \(p\) or not \(q\text{.}\)
    🔗
    🔗
    Both are valid arguments in the context of formal logic, but one is true, while the other has little merit. The actual content contained within the statement variables \(p\text{,}\) \(q\text{,}\) and \(r\) is irrelevant to our analysis. The structure is what matters.
    🔗
    🔗

    Subsection Statements and Arguments.

    Whenever you are studying a new branch of mathematics, you weant to start with a rigorous foundation. You’ll want to define the space and the elements that live within it, impose some additional structure on that space, and then explore the consequences. So, in order to do that, we need some definitions:
    🔗

    Definition 0.1.1.

    A statement (or proposition) is a sentence that is true or false but not both.
    🔗
    🔗

    Definition 0.1.2.

    An atomic statement is a statement that cannot be divided into smaller statements.
    🔗
    🔗

    Definition 0.1.3.

    A molecular statement is a statement that is not atomic.
    🔗
    🔗
    Ways to combine statements:
    🔗
    • The conjunction (i.e., “and”) of \(p\) and \(q\) (\(p \land q\)) is true when \(p\) and \(q\) are both true, and false otherwise.
      🔗
    • The disjunction (i.e., “or”) of \(p\) and \(q\) (\(p \lor q\)) is true when either \(p\) or \(q\text{,}\) or possibly both \(p\) and \(q\text{,}\) are true, and false otherwise.
      🔗
    • The negation (i.e., “not”) of \(p\) (\(\sim p\) or \(\lnot p\)) is true when \(p\) is false, and false otherwise.
      🔗
    🔗

    Subsubsection Truth Tables

    To more easily define these terms, we introduce the concept of a truth table. What makes formal logic so nice to work with is the fact that each of the individual statements can only take on one of two values, \(T\) (True) or \(F\) (False). So, we enumerate them.
    🔗
    Consider the truth table for \(p \land q\text{:}\)
    🔗
    \(p\) \(q\) \(p \land q\)
    \(T\) \(T\) \(T\)
    \(T\) \(F\) \(F\)
    \(F\) \(T\) \(F\)
    \(F\) \(F\) \(F\)
    Consider the truth table for \(p \lor q\text{:}\)
    🔗
    \(p\) \(q\) \(p \lor q\)
    \(T\) \(T\) \(T\)
    \(T\) \(F\) \(T\)
    \(F\) \(T\) \(T\)
    \(F\) \(F\) \(F\)
    Consider the truth table for \(\lnot p\text{:}\)
    🔗
    \(p\) \(\lnot p\)
    \(T\) \(F\)
    \(F\) \(T\)
    These tables give us an easy framework to understand more complicated combinations of statements.
    🔗

    Examples.

    Here we’ll run through a couple more truth tables so you can see what they might look like in more complicated situations.
    🔗
    Example 0.1.4. Exclusive Or.
    In logic, the word “or” is inclusive; that is, it includes the case in which both statements are true. It is useful to have a notion of an exclusive or that is only true when exactly one of \(p\) and \(q\) are true. I claim that the following statement form represents this concept:
    🔗
    \begin{equation*} p \oplus q := (p \lor q) \land \lnot (p \land q). \end{equation*}
    🔗
    Show that \(p \oplus q\) is true when exactly one of \(p\) and \(q\) is true by constructing a truth table.
    🔗
    Solution.
    We will construct a truth table for the statement \(p \oplus q\text{.}\)
    🔗
    \(p\) \(q\) \(p \lor q\) \(p \land q\) \(\lnot (p \land q)\) \((p \lor q) \land \lnot (p \land q)\)
    \(T\) \(T\) \(T\) \(T\) \(F\) \(F\)
    \(T\) \(F\) \(T\) \(F\) \(T\) \(T\)
    \(F\) \(T\) \(T\) \(F\) \(T\) \(T\)
    \(F\) \(F\) \(F\) \(F\) \(T\) \(F\)
    The last column is true when exactly one of \(p\) and \(q\) is true, as desired.
    🔗
    🔗
    🔗
    Example 0.1.5.
    Example 2: Draw the truth table for the statement \((p \land q) \lor \lnot r\text{.}\)
    🔗
    Solution.
    We will construct a truth table for the statement \((p \land q) \lor \lnot r\text{.}\)
    🔗
    \(p\) \(q\) \(r\) \(p \land q\) \(\lnot r\) \((p \land q) \lor \lnot r\)
    \(T\) \(T\) \(T\) \(T\) \(F\) \(T\)
    \(T\) \(T\) \(F\) \(T\) \(T\) \(T\)
    \(T\) \(F\) \(T\) \(F\) \(F\) \(F\)
    \(T\) \(F\) \(F\) \(F\) \(T\) \(T\)
    \(F\) \(T\) \(T\) \(F\) \(F\) \(F\)
    \(F\) \(T\) \(F\) \(F\) \(T\) \(T\)
    \(F\) \(F\) \(T\) \(F\) \(F\) \(F\)
    \(F\) \(F\) \(F\) \(F\) \(T\) \(T\)
    🔗
    🔗
    🔗
    🔗

    Subsubsection Logical Equivalence

    Def. Two statements, \(p\) and \(q\text{,}\) are said to be logically equivalent if, and only if, they have the same truth value under any assignment of truth values to their atomic parts. If \(p\) and \(q\) are logically equivalent, we write \(p \equiv q\text{.}\)
    🔗
    Essentially, two statements are logically equivalent if they have identical columns on a truth tables.
    🔗

    Examples.

    Example 0.1.6.
    Example 1: \(p\) and \(\lnot (\lnot p)\) are logically eqivalent (i.e., \(p \equiv \lnot(\lnot p)\)).
    🔗
    Solution.
    Consider the truth table for \(p\) and \(\lnot (\lnot p)\text{:}\)
    🔗
    \(p\) \(\lnot p\) \(\lnot (\lnot p)\)
    \(T\) \(F\) \(T\)
    \(F\) \(T\) \(F\)
    The two columns are identical, so \(p \equiv \lnot (\lnot p)\text{.}\)
    🔗
    🔗
    🔗
    Example 0.1.7.
    Are \(\lnot (p \land q)\) and \(\lnot p \land \lnot q\) logically equivalent? That is, can you distribute the negation over the conjunction?
    🔗
    Solution.
    Consider the truth table for \(\lnot (p \land q)\) and \(\lnot p \land \lnot q\text{:}\)
    🔗
    \(p\) \(q\) \(p \land q\) \(\lnot (p \land q)\) \(\lnot p\) \(\lnot q\) \(\lnot p \land \lnot q\)
    \(T\) \(T\) \(T\) \(F\) \(F\) \(F\) \(F\)
    \(T\) \(F\) \(F\) \(T\) \(F\) \(T\) \(F\)
    \(F\) \(T\) \(F\) \(T\) \(T\) \(F\) \(F\)
    \(F\) \(F\) \(F\) \(T\) \(T\) \(T\) \(T\)
    The two columns are not identical:
    🔗
    \(p\) \(q\) \(\lnot (p \land q)\) \(\lnot p \land \lnot q\)
    \(T\) \(T\) \(F\) \(F\)
    \(T\) \(F\) \(T\) \(F\)
    \(F\) \(T\) \(T\) \(F\)
    \(F\) \(F\) \(T\) \(T\)
    Hence \(\lnot (p \land q) \not\equiv \lnot p \land \lnot q\text{,}\) so you cannot distribute negations over conjunctions.
    🔗
    🔗
    🔗
    As we saw in Example 0.1.7, negations do not distribute over conjunctions. So how do you negate conjunctions?
    🔗
    🔗
    🔗

    Subsubsection De Morgan’s Laws

    What is the opposite of the statement “I like Math and I like Data Science”? For the statement to be true, both atomic statements “I like Math” and “I like Data Science” need to be true. So, if the statement to be false, at least one of those atomic statements needs to be false. So:
    🔗
    \(\lnot\) (I like Math and I like Data Science) \(= \lnot\) (I like Math) \(\lor \lnot\) (I like Data Science)
    🔗
    That is, I claim \(\lnot (p \land q) \equiv \lnot p \lor \lnot q\text{.}\)
    🔗
    \(p\) \(q\) \(p \land q\) \(\lnot (p \land q)\) \(\lnot p\) \(\lnot q\) \(\lnot p \lor \lnot q\)
    \(T\) \(T\) \(T\) \(F\) \(F\) \(F\) \(F\)
    \(T\) \(F\) \(F\) \(T\) \(F\) \(T\) \(T\)
    \(F\) \(T\) \(F\) \(T\) \(T\) \(F\) \(T\)
    \(F\) \(F\) \(F\) \(T\) \(T\) \(T\) \(T\)
    Similarly, \(\lnot (p \lor q) \equiv \lnot p \land \lnot q\) (prove this!).
    🔗
    These equations are known as De Morgan’s Laws:
    🔗
    \begin{equation*} \lnot (p \land q) \equiv \lnot p \lor \lnot q, \end{equation*}
    \begin{equation*} \lnot (p \lor q) \equiv \lnot p \land \lnot q. \end{equation*}
    🔗
    🔗

    Subsubsection Tautologies and Contradictions

    For a copmplete foundation, we need two more definitions:
    🔗

    Definition 0.1.8.

    A tautology is a statement that is always true.
    🔗
    🔗

    Definition 0.1.9.

    A contradiction is a statement that is always false.
    🔗
    🔗

    Example 0.1.10.

    Show that \(p \land \lnot p\) is a contradiction.
    🔗
    Solution.
    Consider the truth table for \(p \land \lnot p\text{:}\)
    🔗
    \(p\) \(\lnot p\) \(p \land \lnot p\)
    \(T\) \(F\) \(F\)
    \(F\) \(T\) \(F\)
    Since \(p \land \lnot p\) is always false, it is a contradiction. Hence, \(p \land \lnot p \equiv \mathbf{c}\text{.}\)
    🔗
    🔗
    🔗

    Example 0.1.11.

    Show that \(p \lor \mathbf{t} \equiv p\text{.}\)
    🔗
    Solution.
    Consider the truth table for \(p \lor \mathbf{t}\text{:}\)
    🔗
    \(p\) \(\mathbf{t}\) \(p \lor \mathbf{t}\)
    \(T\) \(T\) \(T\)
    \(F\) \(T\) \(F\)
    Since \(p \lor \mathbf{t}\) is equivalent to \(p\text{,}\) we have \(p \lor \mathbf{t} \equiv p\text{.}\)
    🔗
